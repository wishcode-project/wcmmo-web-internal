Every MMO starts with a lot of work nobody sees. This week we set up the server our world will run on.

## What's done

- **A server built to hold a crowd.** We tuned it from the start for a busy world, so big fights and busy towns don't turn into a slideshow.
- **The core toolset** for building, managing worlds and placing NPCs.
- **An empty world, on purpose.** The world starts as a void, so every region you'll explore is hand-built, not generated.

## What's next

Next we prove the scary parts before we build content on top of them: combat that feels good, and systems that no plugin gives us out of the box.

See you in the next log.
